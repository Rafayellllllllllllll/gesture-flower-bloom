# 手势花朵 · 指尖绽放

用摄像头识别手部动作，控制一朵发光粒子花在指尖绽放：握拳时收成花苞，张开手掌时粒子向外扩散成花朵，并会轻微跟随手掌位置摆动。

## 玩法

- 点「开启摄像头」，把手放在画面中央。
- 握拳：花苞聚合；慢慢张开手掌：花朵绽放。
- 没有摄像头时，点「演示模式」也能看到花开花合。
- 右侧选项可以开关手部骨架、摄像头背景、镜像，改粒子数量（5000 / 12000 / 20000）和背景亮度。

## 本地运行（必须用 HTTP 服务，不能直接双击打开）

摄像头和 ES Module 都要求在 http(s) 下运行，直接用 `file://` 打开会失败：

```bash
cd gesture-flower-bloom
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`，允许摄像头权限即可。

也可以用其他静态服务，例如 `npx serve .`。

## 技术栈

- Three.js：3D 粒子渲染，`Points` + `ShaderMaterial`。
- MediaPipe Hands：手部 21 个关键点识别。
- 原生 JavaScript + HTML / CSS，不用构建工具，直接用 ES Module + CDN。

## 核心公式

### 1. 手掌张开度 tension（0~1）

取手腕（关键点 0）到 4 根手指指尖（8、12、16、20）的平均距离 `d_指尖`，
取手腕到 4 个指根关节（5、9、13、17）的平均距离 `d_指根`：

```
ratio = d_指尖 / d_指根
tension = clamp((ratio - 1.25) / (1.95 - 1.25), 0, 1)
```

标定说明：握拳时指尖卷回，指尖距离接近指根距离，ratio 约 1.25；
完全张开时指尖远得多，ratio 约 1.95。算出原始值后会再做一次平滑，
避免单帧抖动。

### 2. 绽放程度 spread

```
spread_target = smoothstep(0.32, 0.66, tension)
```

即 tension 小于 0.32 为花苞、大于 0.66 为全开，中间用 smoothstep 平滑过渡，
不会在阈值处突然跳变。

### 3. 每帧缓动

```
currentSpread += (targetSpread - currentSpread) * 0.1
```

### 4. 花瓣形状（重瓣牡丹版，2026-10-28 第二次重做）

花朵共 4 层、每层 12 片、共 48 片花瓣，呈半球形穹顶放射状交错排列：
花心内层（最短、最密、最卷曲）、内圈（较短、交叠紧实）、
中圈（明显变宽变长）、外圈（最大最宽、向外舒展、边缘起伏）。
每层有独立的半径、角度偏移、深度、宽度、长度和弯曲，角度带随机错开，
避免排成机械圆环。

### 5. 逐层绽放与收拢

整体进度先映射到每层的窗口：花心内层 0.00~0.55、内圈 0.15~0.70、
中圈 0.35~0.85、外圈 0.55~1.00；张开时花心先松开、内圈、中圈、外圈依次展开，
握拳时整体进度下降、同一窗口自然反向：外圈先合拢、花心最后保持紧凑。
再按方向给不同缓动速率（张开时内层快、外层慢；收拢时外层快、内层慢），
手势快速变化时也不会跳变或闪烁。

### 6. 单片花瓣：边缘密集、内部稀疏（2026-10-28 第三次重做）

每片花瓣是独立的采样单元：约 55% 的粒子沿轮廓带采样（70% 两侧边缘、
20% 尖部弧线、10% 根部，侧缘粒子向内按指数分布、平均约 0.16 个单位，
另有约 12% 的侧缘粒子向外散逸最多 0.07），约 45% 的粒子均匀采样在花瓣内部。
边缘距离按到侧缘、尖部、根部的最小距离计算，越靠近边缘粒子越亮、稍大，
内部粒子较细、较淡，但这只是加强——密度差本身由采样分组决定，不是只调透明度。
每片还有独立亮度（0.85~1.07），相邻花瓣靠亮度、角度错开和深度差分清分界，
不画生硬的实线边框。边缘和内部粒子都用同一组花瓣局部坐标算出盛开和花苞位置，
随花瓣折叠一起变形，不会脱离花瓣。

### 7. 控制面板显示 / 隐藏

页面右下角有一个 56 像素的圆形悬浮按钮，固定不动。控制面板显示时按钮
显示收起图标 `‹`，点击后整个控制面板（含标题卡片和所有控件）以 0.25 秒
过渡淡出，花朵画布本身就是全屏的，所以展示区域自然完整；再次点击
（此时按钮显示菜单图标 `☰`）可完整恢复。隐藏只改界面显示，不重置粒子、
不关摄像头、不停手势、不改任何参数。默认首次进入显示控制面板。

对每个粒子，取沿瓣方向 `u`（0=根部，1=尖部）和横向 `v`（-1~1），
瓣宽轮廓为：

```
halfW(u) = W * sin(pi * u^1.15)^0.8
```

根部收窄、中部最宽、尖部圆收；横向采样用带符号平方 `v' = sign(v)*v^2`，
让粒子向花瓣中心线集中、边缘逐渐稀疏。花瓣曲面还有杯状弯曲、
每瓣独立的倾角和起伏，不在同一平面。花心是另外 15% 的粒子：
60% 构成金色球形花心，40% 是向外探出的花蕊点，颜色在明亮金黄与暖白之间过渡。

花苞不是整体缩放，也不是竖直光柱：花瓣按 `fold = u * 1.15` 弧度折叠，
根部基本不动、尖部向前折约 66 度，径向缩短、横向收窄、向前探出，
由平面变成包拢的杯状花苞。竖屏下整朵花还会按可视宽高自适应缩放，
保证直径约 6 个单位的花朵完整出现在画面内，不会被裁成一竖条。

### 5. 粒子插值（顶点着色器里做）

每个粒子存两套位置：`aClosed`（花苞聚合位置）和 `aOpen`（绽放位置），
顶点着色器里用 `mix(aClosed, aOpen, uSpread)` 插值，再加一点呼吸摆动。
这样 CPU 每帧不用更新上万个点的位置，性能只取决于 GPU。

## 摄像头与错误提示

- 拒绝权限：提示去浏览器地址栏旁改权限，并说明需要 https 或 localhost。
- 找不到摄像头 / 被占用 / 页面不安全：都会在页面上给出中文提示和「重新尝试」按钮。
- 长时间检测不到手：花朵会慢慢回落成花苞，骨架画布会被清空。
- 移动端：默认用前置摄像头，页面做了响应式适配。

## 文件结构

- `index.html`：页面结构、控制面板、公式说明。
- `style.css`：深色玻璃拟态界面、响应式布局。
- `main.js`：手势计算、粒子生成、着色器、摄像头与主循环。
